🧠 Multimodal Dementia Detection System
MRI + Audio + Cognitive Tests • Deep Learning + Machine Learning • Streamlit App

This project is a multimodal AI system that predicts dementia stages by combining MRI brain scans, speech/audio features, and cognitive test scores.
The final output is generated using a fusion model that merges predictions from all modalities.

This project demonstrates:
✔ End-to-end deep learning pipeline
✔ Audio-based ML classification
✔ Cognitive assessment integration
✔ Fusion of 3 different modalities
✔ Fully interactive Streamlit Web App
✔ Clean, modern UI
